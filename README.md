# Tracks & Trade

直接打开 index.html，或通过静态服务器访问。无构建步骤。

## 当前玩法（v0.14）

玩家建设产线、连接道路、探索新市场。货物只存在于地块和运输途中，金币是唯一购买货币。

- 开局 2,600：伐木营 1,200、两段路 750、首名工人 300，可直接启动自动收入。手工生产是可选加速。
- 生产、运输、闲置免费。建筑、道路、工人按实付费用全额退款。
- 六种货物、六类建筑。原木同时用于木板、石头工具和铁，配方竞争共享原料。
- 城镇每回合收购 min(库存,需求)，点城镇只查看。需求 = 2 × 居民 × 时代倍率；居民最多 3 名。
- 每座工坊最多 3 名工人，自动产量 = 工人数 × (1 + 对应工艺等级)。手工每次 = 1 + 对应工艺等级，无独立点击科技。
- 产出先发货，剩余最多积压 20 件；原料仓包含工作批次加 20 件余量。在途预约补足路程，不把仓储当作吞吐上限。
- 道路每段 250 × 地形系数，只决定连通和延迟；没有运力、道路等级或运费。
- 七格板块按章节探索：石头城镇→岩地→木板城镇→森林→工具城镇→岩地→铁城镇→铁矿。缺失原料优先补齐；五种商品后进入双货市场和扩容。布局随机且自动定向。
- 工艺价格只随类型和等级增长；时代价格只随时代等级增长。探索价格为 round(600 × [1 + 0.35(n−1)]^1.35)，不挂当前收入。
- 目标仅有收入和探索。收入目标翻倍、探索目标加一，奖励 100–249；产出、运输与销量留在诊断统计中。

## 设计与验证

UI 修改先更新 docs/ui-system.html 的规范与示例，再同步原型，见 AGENTS.md。共享组件示例不读写玩家存档。

玩法和真实引擎经济模拟见 docs/design.html；规则见 docs/rules.html。economy-model.js 提供确定性经营策略，设计页与命令行共用，衡量首次售出、购买等待和投资类型；不是最优解或所有玩家体验的保证。

运行规则与节奏测试：

~~~sh
node --test tests/economy.test.cjs tests/progression.test.cjs tests/pacing.test.cjs tests/map-geometry.test.cjs
node tools/mapgen-sim.cjs 5 600
~~~

一回合 2 秒；隐藏页面即暂停，不追赶离线时间。存档键沿用 tnt-mvp-v17，数据格式为 v22。自动迁移 v19–v21：保留地图与进度，清除旧维护费负债，退回被移除金手指的原始升级费用并删除退休目标。重复加载不会重复退款。

旧 tests/ui.cjs 对应早期原型；当前浏览器回归见 tests/progression-ui.cjs。engine.js 是规则来源，game.js 负责交互与展示。
