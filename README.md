## 当前玩法（v0.14）

玩家建设产线、连接道路、探索新市场。产品保存在地块，接通城镇自动出售，金币是唯一购买货币。

- 开局自带免费的伐木营、两段道路和 1 名工人，自动出售原木；余额 2,600 可自由投资，不再预留首路资金。手工生产是可选加速。
- 生产、运输、闲置免费。建筑、道路、工人按实付费用全额退款。
- 十种货物、十类生产建筑。原木同时用于木板、石头工具和铁，配方共享运行中的上游连接。
- 城镇不限量收购，每件产品只卖一次，优先相连的最高价市场；居民和时代每级增加基础售价的 25%，加成相加。
- 每座工坊最多 3 名工人，自动产量 = 工人数 × (1 + 对应工艺等级) + 条件研究加成。手工每次 = 1 + 对应工艺等级，无独立点击科技。
- 上游接通且有工人就固定生产；上游产量不限制下游，不逐件消耗原料。未售产品保留，无堵仓停工。
- 道路每段 250 × 地形系数，只决定连通；没有运力、道路等级或运费。
- 七格板块按章节探索：石头城镇→岩地→木板城镇→森林→工具城镇→岩地→铁城镇→铁矿。缺失原料优先补齐；八种可售商品后进入双货市场和扩容。布局随机且自动定向。
- 扩展产业：造纸坊（原木→纸张）、印刷坊（纸张+石头工具→书籍）、炭窑（原木→木炭）、机械厂（木板+铁+木炭→机械）。铁之后探索纸张、书籍、机械市场，木炭不直接出售。
- 六项可选研究：石工筑路（新路 -20%）、水运工程（湖系数 3→2）、山地工程（山路 ×4）、水力机械（邻湖加工工坊每工人 +1）、专业分工（满员工坊 +3）、深井开采（每矿工 +2、每铁厂工人 +1）。生产加成仅自动生产生效，上游接通即可；不改变地形生成。
- 工艺价格只随类型和等级增长；时代价格只随时代等级增长。探索价格为 round(400 × [1 + 0.25(n−1)]^1.2)，不挂当前收入。
- 目标仅有收入和探索。收入目标翻倍、探索目标加一，奖励 800–1,200；无需定位生产瓶颈。

地图左下「产业规划」整合建造、生产链和科技；科技节点随前置逐层出现，地图详情也能直接购买相关科技。弹窗中切换上游连接关系／研究前置，选择节点后解锁、升级或到地图选址。打开时暂缓回合，关闭后恢复原暂停状态；支持缩放、查看全图、定位和键盘操作。

## 设计与验证

UI 修改先更新 docs/ui-system.html 的规范与示例，再同步原型，见 AGENTS.md。共享组件示例不读写玩家存档。

玩法和真实引擎经济模拟见 docs/design.html；规则见 docs/rules.html。economy-model.js 提供确定性经营策略，设计页与命令行共用，衡量首次售出、购买等待和投资类型；不是最优解或所有玩家体验的保证。

运行规则与节奏测试：

~~~sh
node --test tests/*.test.cjs
node tests/research-ui.cjs
node tools/mapgen-sim.cjs 5 600
~~~

一回合 2 秒；隐藏页面即暂停，不追赶离线时间。存档键沿用 tnt-mvp-v17，数据格式为 v25；旧版在途货物迁移为库存，移除派货预约和瓶颈警报。v23 自动补齐新资源账本与四类建筑科技，历史库存、道路、进度及在途货物保留。v22 存档自动补齐六项未研究科技，保留地图、余额、货物与进度；自动迁移 v19–v21：保留地图与进度，清除旧维护费负债，退回被移除金手指的原始升级费用并删除退休目标。重复加载不会重复退款。

旧 tests/ui.cjs 对应早期原型；当前浏览器回归见 tests/progression-ui.cjs。engine.js 是规则来源，game.js 负责交互与展示。

后续科技随探索开放：发现工具、铁、纸张、书籍、机械市场后，开放对应产业研究；炭窑随机械市场开放。基础采掘、木板与航道依前置开放。时代升级分别需要已探索 2、4、8、12 块地图。已获得的科技保留，工艺可持续升级。
