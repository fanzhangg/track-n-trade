# Tracks & Trade

直接打开 `index.html`，或通过静态服务器访问。没有构建步骤或外部运行依赖。

## 当前版本：v0.10 每回合一件的整数模型

保留 v0.6 的即时建造与拖线连路。核心乐趣是找出并改善物流系统的瓶颈：产量、道路、城镇需求三层各有上限，玩家的钱只有这三个去处，地图只高亮最值得扩容的三段路。设计定稿见 `docs/v10-design.md`。

一 tick 是一回合，1× 速度下一回合两秒。所有数量都是整数件：建筑每回合做几件、道路每回合运几件、城镇每回合收几件，面板上没有小数和换算。

- **建筑：每回合几件。** 伐木营产 2 原木，采石场产 2 石头，锯木厂吃 1 原木出 1 木板。每个模块再加同样的量，高效设备 ×2，密林/富岩地 ×2，蒸汽锯让锯木厂再 ×2。每座建筑门口的堆场最多放 20 件，堆满就停工，地图上标出数量。
- **道路：每回合两件。** 普通路每回合放行 2 件，扩容后 6 件，货运马车再 ×2。两种货或两个方向共用一条路时轮流放行，运力不会因为连的建筑多而变高。货物过一段路花 1 回合。
- **城镇：每回合收 N 件，开局就能喂饱。** 每座城镇对它收的每种货每回合收 1 件，需求最多攒 20 回合。开局的三座工厂连上西镇后正好把西镇喂饱，收入到顶；之后要涨收入只能花钱扩建城镇，每级每种货每回合多收 1 件。城镇被喂饱时地图和目标条标出「已满」。价格固定按件计：西镇原木 20 / 石头 30；南镇木板 50 / 石头 40 / 原木 10；东集（需架桥）木板 90 / 原木 30 / 石头 50。城镇不会自己升级。
- **定价不随全图数量增长。** 新建筑固定价：伐木营 1200、锯木厂 2400、采石场 1600；同一建筑上每多一个模块 ×1.25。道路每段 250 × 地形系数（草地/城镇 ×1，森林/岩地 ×2，密林/富岩地 ×3），桥 ×3，已有路段免费复用；扩容 = 该段造价 ×3。高效设备 4000 × 1.5^n，城镇扩建 1500 × 1.5^L。拆除、降级退实付的一半。
- **只能修有货可运的路。** 伐木营↔锯木厂，以及生产建筑↔收该货的城镇；其他连接会被拒绝并说明原因。
- **地图只高亮三段路。** 引擎每 tick 把没运出去的需求按门口价格归咎到它路线上跑满的路段；近 30 回合累计最高的三段依次标红、橙、黄，其余道路一律灰色。选中道路的面板写出「扩容优先级第 N 位 · 堵住约 X 金币/回合」。文字颜色只有三种：红橙黄是扩容优先级，琥珀色是正在损失价值（堆场已满、城镇需求已满、缺原木），其余一律默认色。
- 全局科技就在工具栏里，和三个建筑按钮并排：货运马车 16000（所有道路运力 ×2）、蒸汽锯 30000（所有锯木厂 ×2），买过的显示对勾。里程碑列表在什么都没选中时的右侧面板里。十五项里程碑付金币，全部完成后目标条隐藏；长期目标（科技树/新区域）留待下一阶段。
- 开局 1000 金币，正好够把采石场连到西镇（岩地、森林两段路，500 + 500）。南镇三段草地路 750，东集需桥 2250。

## 交互（v0.6 起）

- 从工具栏拖建筑到合法地形，松开立即建成。伐木营和采石场无需道路即可生产；锯木厂接收原木后加工。
- 按住地图上的建筑或城镇，拖到另一座建筑或城镇再松开，自动铺好整条连接并显示金币造价。自动绕山，跨河直接建桥。
- 生产在当地进行，道路有共享运力，货物每段路走 1 回合。

## 验证

```sh
node --test tests/economy.test.cjs
```

`tests/economy.test.cjs` 验证整数不变量、每回合一件的生产与道路速率、共用道路轮流放行、按段定价与地形系数、金币门槛与原子失败、连接合法性、有限需求池与不超发、付费城镇扩建、道路归咎排序、退款、存读档一致。`tests/ui.cjs` 是独立 Playwright 回归脚本（非法连接被拒、金币不足不修、连路售卖、城镇格只显示收入、刷新保留），依赖本机 Edge 与所配置的 Playwright 路径。v0.5–v0.7 的材料施工测试归档于 `tmp/v7/`。

`assets/` 存放界面用的像素图标（Kenney Tiny 系列，CC0，来源见 `assets/README.md`）。`engine.js` 负责固定步长模拟、定价与城镇收购，`game.js` 负责直接操作、目标条与诊断，`game.css` 为简洁响应式布局。v0.5 界面备份位于 `tmp/prototype-v5/`。
