# Tracks & Trade

直接打开 `index.html`，或通过静态服务器访问。没有构建步骤或外部运行依赖。

## 当前版本：v0.11 点击生产与工人

建筑不会自己生产：**点一下伐木营出一根原木**。想让它自动产货，就得给它雇工人，一名工人每回合自动做一件。物流永远是自动的，修好路货就自己跑去城镇卖掉。设计定稿见 `docs/v11-design.md`，上一版的整数模型见 `docs/v10-design.md`。

一 tick 是一回合，1× 速度下一回合两秒。所有数量都是整数件：工人每回合做几件、道路每回合运几件、城镇每回合收几件，面板上没有小数和换算。

- **产量只看工人数，每座建筑最多 3 名。** 一次点击做 `1 + 工具改良等级` 件，一名工人每回合做 `1 + 工人培训等级` 件，建筑本身产能为零。建筑类型、地形、设备都不再影响产量，工人效率是全局科技。三个槽位满了之后，涨产量只能靠开新建筑或买工人培训，所以扩张是横向的。锯木厂 1 原木换 1 木板，点击和工人都要吃原木。每座建筑门口的堆场最多放 20 件，堆满就停工，点击也会被拒绝。点击产量和工人产量一起记进当回合的统计。
- **道路：每回合四件。** 普通路每回合放行 4 件，扩容后 12 件，货运马车再 ×2。两种货或两个方向共用一条路时轮流放行，运力不会因为连的建筑多而变高。货物过一段路花 1 回合。
- **城镇：每回合每种货收 2 件。** 每买一级再多收 2 件，需求最多攒 20 回合。价格固定按件计：西镇原木 20 / 石头 30；南镇木板 50 / 石头 40 / 原木 10；东集（需架桥）木板 90 / 原木 30 / 石头 50。城镇不会自己升级，只能花钱扩建。被喂饱时地图和目标条标出「已满」。
- **定价不随全图数量增长。** 新建筑固定价：伐木营 1200、锯木厂 2400、采石场 1600。工人按建筑算：伐木营 400、采石场 600、锯木厂 1000，同一建筑每多一名 ×1.3，最多 3 名。道路每段 250 × 地形系数（草地/城镇 ×1，森林/岩地 ×2，密林/富岩地 ×3），桥 ×3，已有路段免费复用；扩容 = 该段造价 ×3。工人培训 5000 × 2ⁿ，工具改良 2000 × 2ⁿ，城镇扩建 1500 × 1.5^L。拆除、辞退、降级退实付的一半。
- **只能修有货可运的路。** 伐木营↔锯木厂，以及生产建筑↔收该货的城镇；其他连接会被拒绝并说明原因。
- **地图只高亮三段路。** 引擎每 tick 把没运出去的需求按门口价格归咎到它路线上跑满的路段；近 30 回合累计最高的三段依次标红、橙、黄，其余道路一律灰色。选中道路的面板写出「扩容优先级第 N 位 · 堵住约 X 金币/回合」。文字颜色只有三种：红橙黄是扩容优先级，琥珀色是正在损失价值（堆场已满、城镇需求已满、缺原木），其余一律默认色。
- 全局科技就在工具栏里，和三个建筑按钮并排：工人培训、工具改良、货运马车 16000（所有道路运力 ×2）。里程碑列表在什么都没选中时的右侧面板里，达成付金币，全部完成后目标条隐藏；长期目标（科技树/新区域）留待下一阶段。
- **开局只有一座伐木营**（西镇隔壁的森林）和 1000 金币，没有道路。点二十下原木，卖掉刚好够雇第一名工人；采石场、锯木厂、路网和科技由玩家自己摸索，里程碑给方向。西镇一段森林路 500，南镇三段草地路 750，东集需桥 2250。

## 交互

- 点地图上的建筑生产一件并选中它；点城镇只选中。侧栏的「手工生产 n 件」做同样的事，方便键盘和触屏。
- **工人画成 Cookie Clicker 的 cursor。** 每雇一名工人，建筑下方就多一只手指，没雇的槽位不画，界面上看不出上限。每只手指按自己的节拍朝建筑点一下，一个回合里几名工人均匀错开，所以工人越多看到的点击越密，这就是速率。工人培训缩短节拍，格子上标出「×n」。建筑停工或游戏暂停时，手指回到静止位置并变灰，不会冻在半空。
- 从工具栏拖建筑到合法地形，松开立即建成。
- 按住地图上的建筑或城镇，拖到另一座建筑或城镇再松开，自动铺好整条连接并显示金币造价。自动绕山，跨河直接建桥。
- 生产在当地进行，道路有共享运力，货物每段路走 1 回合。

## 验证

```sh
node --test tests/economy.test.cjs
```

`tests/economy.test.cjs` 验证开局只有一座没有工人的伐木营、点击生产与堆场上限、工人是唯一的自动产能、点击与工人产量记进同一个统计样本、每回合四件的道路速率、共用道路轮流放行、整数不变量、按建筑的工人定价与翻倍科技、按段定价与地形系数、金币门槛与原子失败、连接合法性、有限需求池与不超发、付费城镇扩建、道路归咎排序、退款、存读档一致。`tests/ui.cjs` 是独立 Playwright 回归脚本（非法连接被拒、金币不足不修、连路售卖、城镇格只显示收入、刷新保留），依赖本机 Edge 与所配置的 Playwright 路径，尚未按 v0.11 更新。v0.5–v0.7 的材料施工测试归档于 `tmp/v7/`。

`assets/` 存放界面用的像素图标（Kenney Tiny 系列，CC0，来源见 `assets/README.md`）。`engine.js` 负责固定步长模拟、点击与工人产能、定价与城镇收购，`game.js` 负责直接操作、目标条与诊断，`game.css` 为简洁响应式布局。v0.5 界面备份位于 `tmp/prototype-v5/`。
