规则说明书

这是给玩家看的完整规则。Tracks & Trade 是一个单人物流建设游戏：你点击、雇人、铺路、揭开地图、买科技；系统自动把货送到需要它的地方、卖成金币。你设计网络，系统跑网络。本页列出每一条规则和每一个数字，需要什么翻到哪一节即可。

你在玩什么

地图上有森林、岩地、铁矿这样的资源地形，和收购货物的城镇。资源在原地才能开采，城镇只收送到门口的货。你要做的事只有四种：

建

在合适的地形上放建筑：伐木营出原木，采石场出石头，锯木厂把原木变木板……每座建筑要先解锁科技（伐木营除外）；可在地块详情直接解锁。

连

在「产这种货」和「收这种货」的两点之间修路。路修好以后货自己走，你不用指挥任何一趟运输。

探

花金币揭开相邻的迷雾板块。揭开后可以旋转六个朝向，放下就不能再转。新板块里可能有新城镇、新资源，也可能有挡路的山和湖。

买

金币是唯一的货币。工人、建筑、道路、板块、科技、城镇扩建全部用金币买，货物永远不进你的口袋。

没有输，没有倒计时。游戏不会结束。你在优化的是「等多久才能攒够下一件事」，而不是「能不能」。任何东西拆掉都全额退款，布局错了随时重来。

开局

开局余额 $2,600，自带免费的伐木营、连接起始城镇的两段道路和 1 名工人，直接自动卖原木；初始设施退款 $0。没有首路资金预留或强制操作顺序，手工生产是可选加速。继续扩产或花 600 探索石头城镇，下一块会提供岩地。

时钟与整数

  • 游戏按回合走。1× 速度下一回合 2 秒。顶栏可切换 1× / 2× / 5×，倍速只压缩真实时间，不改变任何数量。
  • 暂停按钮停下模拟；把页面切到后台也会暂停，回来时不会补算你离开的时间。没有离线收益。
  • 预览新板块时模拟自动暂停，放下板块后继续。
  • 所有数量都是整数件。产量按件、城镇按件收、价格按件算。
  • 面板上的「近期」「实际」都指最近 30 回合的平均值，不足 30 回合按已有样本算。
  • 同一个存档、同样的操作顺序，结果完全一样。板块里出现什么由存档种子决定，不是纯随机。

地图与探索

地图由七格花铺成。起始花固定：原木城镇、森林、草地和山；其余板块在购买时由种子、当前缺口和解锁顺序决定，方向自由选择，自动定向，不提供旋转或预览。

探索按「新买家 → 配套资源」交替推进：石头城镇 → 岩地 → 木板城镇 → 森林与加工空地 → 工具城镇 → 岩地 → 铁城镇 → 贴山铁矿。若旧地图存在缺失原料，先补原料；多种缺口逐块补齐。工厂建在资源上也算已有产地，不会因雇工或建厂把探索卡在补森林。

发现顺序引导科技，但不会免费解锁科技。先展示新的销售机会，玩家再决定投资哪条链。所有八种可售商品出现后，城镇引入双货需求，资源板块补其配套原料；挑战转向共享原料、选址与扩容。有限的配方不意味着无限的新机制。

森林、山脉和水域跨板块连片生长；常规板块有 2–3 格山水，河流以狭长水格延续。草地山口与绕行路线保持连通，未探索邻块保留陆路入口；航道解锁后可以跨水取捷径。铁矿邻山，城镇不与所需原料同块或紧贴；石头城镇周围也可有森林。产业发现节奏不变，地形与朝向随种子和邻地变化。

新产业接在铁之后：纸张市场 → 森林 → 书籍市场 → 岩地 → 机械市场 → 铁矿。所需森林等原料若缺失仍优先补齐；新建筑使用草地，不增加地形或重绘已探索板块。已有存档继续探索即可发现新市场。八种可售商品均引入后，再生成双货市场。

纸张可以直接卖，也可和石头工具一起制成书籍；木炭不能直接卖，机械需要木板、铁、木炭同时供应。原木上游可供造纸、烧炭、炼铁、木板与工具共享；各链独立按工人和科技生产。

每座新增工坊仍最多 3 名工人，独立工艺全图生效；水力机械、专业分工同样适用。研究、建造、工人与工艺各自付费；生产与运输不收费。

接通就生产

每座工坊最多 3 名工人。连接每种所需原料的运行中上游、并雇用工人后，每回合固定产量 = 工人数 ×（1 + 对应工艺等级）+ 条件科技加成。上游自身也必须满足连接条件且有工人；同一个上游可支持任意多个下游，无需配平各段产量，不逐件消耗原料。连接关系可经过任意长度的道路网络。

未接通市场的产品会保留，不设库存上限，不会停工。道路断开或上游最后一名工人被辞退时，对应下游停止生产；恢复条件即可继续。手工生产可选，每次为 1 + 工艺等级，不需要本厂工人，但加工厂仍需运行中的上游。

道路

  • 怎么修：选中建筑，在详情里选择「从这里修路」，再点选另一座有建筑的板块。系统自动规划路线与造价，钱不够时拒绝。
  • 只连接建筑：两端都必须有建筑；道路可跨过空地，但不能以空地或已有道路作为起点或终点。
  • 路线自动选：每次连接两座建筑是一条独立道路。系统绕开已有道路和中途建筑，在可行路线中优先选择段数少、费用低的路线；不交叉、不共用路段，只在端点建筑汇合。没有独立路线时会提示探索更多板块。已建成的同一条连接不会重复收费。
  • 造价：每一段 $250 × 地形系数，系数取两端地形中较高的那个（草地和城镇 1，森林、岩地、铁矿 2，湖 3，山地工程后山 4；水运工程将湖降为 2，石工筑路再将新修费用乘 0.8）。例如伐木营（森林）到相邻草地这一段 $500，草地到城镇 $250。
  • 道路只负责连通。没有运力上限、没有等级。连通后每回合立即结算生产与销售，路长不降低收入。
  • 新修的路段下一回合开始通货。
  • 每件货走段数最少的路线；已经上路的货不会掉头。
  • 拆路：点选道路，在面板里选择「拆除整条路」，只拆除这两个端点之间的道路，其他连接保留。旧存档中没有独立归属的路段在建筑或分岔处划分管理范围。拆除后立即不再有新货进入，下一回合退回整条路的实付造价，结算前可以「撤销拆除」。

道路连接

道路连接上游工坊、加工工坊与城镇；没有运力、货物优先级、预约调度和运费。驴与船只表现活跃连接，不代表运输倒计时。拆路立即停止连接，下一回合按实付金额全额退款，结算前可撤销。

城镇与收入

城镇对自己收购的商品不限量收购。每回合自动卖出所有相连地块的可售库存，每件货只出售一次，优先选择有效单价最高的相连城镇；同价按固定顺序选择。道路长度没有延迟或吞吐惩罚。选择城镇只查看，不手工卖货。

有效单价 = round（生成时基础单价 × [1 + 25% ×（居民数 − 1 + 时代升级数）]）。每城镇最多 3 名居民，每次加居民提升本城镇基础售价 25%；时代升级提升全图基础售价 25%，加成相加。历史收入按成交时单价记录，不随升级改写。

居民费用 = round（各商品基础单价之和 × 12 × 1.5^(已有居民数−1)）。时代费用 = 2,400 × 2^当前时代升级数，最多升级四次。

科技

解锁顺序：采石场 → 锯木厂 → 石匠铺 → 矿山 → 铁厂；锯木厂同时开启可选航道。每种建筑解锁后，同一张科技卡改为购买该类工艺。时代提升全图城镇售价，工艺提升全图同类工人的产量，价格只依赖类型与等级。

工艺价格 = 类型底价 × (等级+1)^1.6；时代价格 = 2,400 × 2^时代等级。手工产量随工艺，无单独点击科技。

可选分支研究

每项只购买一次，全图已有与新建建筑立即适用。卡片列出前置、效果和适用工坊数量；没有合适选址或工人时，研究不会凭空产生收益。科技不退款。

金币、退款与目标

生产、运输与闲置免费。建筑、道路、工人按实付金额全额退款；科技、探索与居民不退。目标只保留收入与探索，达标自动发放 800–1,200 金币。收入目标翻倍，探索目标加一，不因收入回落撤销。

界面与操作

地图左下「产业规划」整合建造、科技与生产链。科技随前置逐层展开；也可在地块、建筑、道路详情直接购买相关科技。切换两种关系图，选择节点查看前置、解锁或升级，再选择「到地图建造」并点选地形。打开规划暂缓回合，关闭后恢复原暂停状态。图支持缩放、全图、定位与键盘操作。

工坊详情只显示固定产量、工人数和上游连接状态；城镇显示不限量收购、售价和近期实际收入。选择建筑可手工生产；从建筑详情发起修路，再点选另一座建筑，路线自动规划。道路可拆除或撤销拆除。探索直接揭开板块，不旋转。

地图保留既有建筑、暖白收入胶囊、蓝灰未开发市场胶囊与驴／船装饰，不显示满仓或瓶颈警报。视觉规范见 设计系统。

存档

  • 游戏自动保存在浏览器本地，顶栏「更多」里能看到保存状态。清除浏览器数据会丢档。
  • 「导出存档」下载一个 JSON 文件，「导入存档」读回来。存档里包含种子和解锁次序，所以换设备后板块内容也一样。
  • 「重新开始」清空当前档，重新给你一朵起始板块、已连路且有 1 名工人的伐木营和 $2,600。
  • v19–v21 数据自动迁移，保留地图与进度；被取消的金手指升级一次性退款，退休的目标移除。更早的数据结构不兼容。

常见问题

必须扩建上游配平产量吗？不用，一个运行中的上游可以共享给多个下游。

为什么工坊没有生产？检查是否有工人，以及各原料是否连接了运行中的上游。无需查看库存或效率。

没有买家会停工吗？不会，产品保留，接通买家后自动出售。

长路需要更多工人或车辆吗？不用，路通即可，驴和船是装饰。

速查

每座工坊最多 3 人；每回合 2 秒；工艺每级每名工人 +1；手工每次 1 + 工艺等级；居民与时代每级基础售价 +25%；不限量收购；无持续费用；拆除按实付退款。价格以游戏购买前显示为准。
