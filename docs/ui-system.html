布局与组件

布局与尺寸

顶栏高 48px；两侧面板距顶部 62px、距边缘 14px，宽 340px，面板间距 10px。建造栏固定在左下。1050px 以下侧栏收窄，740px 以下转为底部堆叠。

文字与容器

原型使用 system-ui / Microsoft YaHei，正文 14px、行高 1.5；余额 20px 粗体，面板标题 12px。面板圆角 12px、6px 背景模糊；按钮圆角 7px、内边距 8px × 12px。

组件与交互

面板标题点击折叠；详情先展示对象、状态、工人或居民与主要动作，再展示产线诊断和近 30 回合数据。拆除、辞退与修路入口收进「管理建筑」。科技使用分层卡片，区分解锁、升级与前置未满足。

组件状态

颜色与层级

画布 → 面板 → 内嵌区域，依靠明度、留白和边界分层。主要数字用字重和字号突出，不把所有收入、价格都涂成金色。

状态

操作与选择

蓝灰主按钮表示当前动作；hover、active 和键盘焦点分别加深或增加轮廓。选中建筑时突出关联生产链，链外地块与道路降至 30% 不透明度。禁用操作保留价格或前置条件。

产线诊断

详情以横条表达输入、生产、运输与收购：绿表示正常，橙表示不足，红表示无供给，配文字、数值和结论。关注行使用浅暖底色；结论有普通、警告与正常状态。

地图反馈

缺料或满仓用右上感叹号；等级在左上，库存保留数字。城镇未连路显示收购价，连路后显示每回合实际收入；饱和货物变红，有积压时另显示积压数量。货流是沿实际曲线移动的纯色小圆点。

地图与货物

地形色表示类别；货物靠图形辨认，颜色辅助。

货物用图形辨认，颜色辅助。

六种货物不是六种货币。小货点沿道路移动，面板始终配图标、名称与当地库存。

空闲地块用材质小景；建筑居中，上方摆棋子，下方显示库存。地形限制放在详情面板。
