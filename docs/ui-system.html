布局与组件

供需与探索

城镇每回合自动收购 min(库存,需求)，库存不足也收；点城镇只查看，不手工卖货。工坊手工生产量随自身工艺成长，无独立金手指科技。目标只保留收入与探索两条。产出堆场的 20 件限制积压，不限制当回合直接发出的货；原料仓显示工作批次加 20 件缓冲的容量。新城镇按原木、石头、木板、工具、铁引入机制，下一块补配套资源；资源位置和布局仍随机。

布局与尺寸

顶栏高 48px，保留余额、一项简洁收入速率、暂停、速度和更多菜单。收入以 12px 次要文字显示“+$100/回合”，采用近 30 回合实际收入均值，悬停说明统计口径；不显示预测值和重复标签。窄屏收入移到余额下方，顶栏仍保持 48px。两侧面板距顶部 62px、距边缘 14px，宽 340px，面板间距 10px。建造栏固定在左下。1050px 以下侧栏收窄，740px 以下转为底部堆叠。

文字与容器

原型使用 system-ui / Microsoft YaHei，正文 14px、行高 1.5；所有金额统一使用美元符号前缀，如 $100、$1,200；收入与奖励写作 +$100，每回合收入写作 +$100/回合，金额进度写作 $100 / $200，不再附加货币单位。余额 20px 粗体，面板标题 12px。面板圆角 12px、6px 背景模糊；按钮圆角 7px、内边距 8px × 12px。付费按钮采用左右布局：左侧 14px / 700 粗体标题，下方 12px 常规字重说明，降低亮度；右侧 18px / 750 等宽数字费用，不换行。费用不再混在说明中。建造栏采用图标加两行文字：上行建筑名称与等级为 14px / 700，下行费用为 12px / 400、85% 不透明度，与名称左对齐并间隔 3px；可建、选中与买不起状态均保持此层级。窄屏详情操作纵向排列，说明可换行，费用保持靠右。标题与费用保持高对比，升级费用沿用白色。

组件与交互

面板标题点击折叠；详情仅在选中对象时出现，对象名称作为标题。工坊首屏直接展示原料运入、消耗、当前库存，产出与自动产能利用率，产品运出与积压；每种货保留名称和单位，上下游建筑名称附在对应区域。城镇逐种货展示收购单价、运入、实际收购量、收购能力、库存与每回合收入，并突出总收入。核心供需信息不折叠；只折叠辞退与拆除等管理。流量统一用近期已记录回合均值，库存为当前值，自动效率排除手工生产。保留建路玩法：从建筑或已有道路地块拖拽修路，预览路线与总造价；建筑详情提供“从这里修路”，可选择终点，Esc 或取消退出。道路不显示运量数字；点击或键盘选择道路打开管理面板，显示退款额与“拆除这段路”。拆除中显示虚线，停止新货进入，等待在途货物通过后全额退款，完成前可“撤销拆除”。拖拽道路仍用于修路。科技仅展示引擎中存在的项目，已移除的科技不留空卡片；科技使用分层卡片，区分解锁、升级与前置未满足。

信息精简：无选中对象时不显示空详情；窄屏直接进入地图，不弹设备提醒。游玩菜单只保留存档、重新开始与规则；玩法设计和 UI 规范从文档导航访问。保留目标、生产链与增长曲线用于规划。详情采用 18px 对象标题、22px 关键数字、12px 次要标签；主操作使用蓝灰底，次级操作保持普通按钮。窄屏面板最多占可用高度的 62%，保留地图操作空间。

组件状态

颜色与层级

画布 → 面板 → 内嵌区域，依靠明度、留白和边界分层。主要数字用字重和字号突出，不把所有收入、价格都涂成金色。

状态

操作与选择

建造与解锁保留蓝灰主按钮；升级（含工艺、时代提升）使用陶土橙底、白色文字的 .upgrade 按钮，以 --action-upgrade 系列色值统一默认、悬停与按下状态。价格文字同样保持白色；键盘焦点保留蓝色轮廓，禁用与买不起沿用现有压暗状态。选中建筑时突出关联生产链，链外地块与道路降至 30% 不透明度。取不到手的东西只有一套画法：.costly（买不起）与 .locked（前置未满足）共用同样的压暗，不靠配色互相区分——.locked 另带一枚锁图标说明被锁住，这就够了。买不起仍可点击，让玩家先规划再攒钱。这套压暗在建造栏、科技卡与详情面板购买按钮上一视同仁。地图迷雾板块整块就是一个按钮，不在板块里再套一个按钮——没有底板、没有边框，板块自己的底色就是按钮的底色，「解锁」与价格直接落在上面。买得起时板块底用实的 --terrain-fog 配主要文字，悬停提亮、可聚焦、指针为手型；买不起时底色换成 --terrain-fog-costly（一块几乎融进地图衬底的淡色），文字压到 55%，并且整块不可交互：不可点、不可聚焦、无悬停反馈。文字留在原处是为了让玩家看见「这里有个东西，只是现在按不动」，而不是以为这块地什么都没有。这一点与建造栏相反——建造栏买不起仍可点，是为了先规划后攒钱；板块没有可规划的余地，点开也只有一个按不动的按钮，索性不让点。建造栏里每个建筑本身就是一个按钮：可建（买得起）直接用主按钮的深蓝底，与科技卡上的「解锁」同级；选中待放置时压到 --action-pressed 并加一圈 --action-subtle 外环；买不起退回普通按钮并压暗。选中态优先于压暗——买不起的建筑一旦被选中，就是当前动作，全强度显示，金币不足由放置时的提示承担。

供需明细

详情采用对照表，不再堆叠逐货物卡片。工坊顺序为“原料 → 生产 → 产品”：原料表对齐运入、消耗与当前库存；生产区对齐实际产出与当前产能，自动效率用一条进度条表示；产品表对齐运出与当前积压。城镇第一张表列货物、单价、每回合收购与收益，表尾汇总总收入；第二张表列运入、收购上限与当前库存。流量统一为近期均值，表头统一标单位，不在每个数字后重复。原料与产品关联建筑名称放在对应表下。主数字 16–22px，表格数字 13px 等宽右对齐；货名左对齐，允许换行。问题提示只显示一次，操作区与数据区用留白分隔，管理可折叠。

地图反馈

目标：默认地图保持简洁，用库存提示积压，选中地块查看产出与瓶颈。建筑和城镇一样，建筑使用 54px 图标框，中心在 (0,-12)，顶部可略越过地块后缘，脚部落在地面上；脚下土面是平整院地：中心 (0,7)、半径 24×9px，覆盖模型脚部并在前方留出少量砂地；与道路共用 --road-dirt，无描边或土堆厚边。道路接入 (0,7)，圆头完全收在院地内，先画道路再画院地和模型，模型保持原透视；棋子使用 16px 图标框与脚下接触阴影，以稳定的散点分布在建筑两侧与前侧，按地块固定轻微偏移，刷新不重新随机。两个独立胶囊采用暖白底、细灰边、轻阴影：常态高 16px，城镇收入始终显示，建筑生产速率仅选中时显示；仅显示红色满仓库存，位于收入或产出下方，间隔 2px，无生产胶囊时放在 y=12；横向间距 2px、内边距 5px，图标与数字间隔 1px；长内容及选中详情允许外扩，不压缩文字。选中详情移到模型下方，高 20px、间隔 2px。胶囊里的元素之间用细竖线隔开。地图胶囊的转换箭头采用 6×4px 的 SVG 短箭头，1.1px 圆头圆角描边，按胶囊中线对齐；占位宽 7px，两侧采用 2px 间距。常态使用次要文字色，红底警示使用半透明白色；资源单价、收入和选中生产明细复用同一箭头，不使用字体箭头。

胶囊视觉。胶囊采用暖白实底（--surface-panel）、浅砂色 0.6px 细边（--border-subtle）和低透明度短阴影；统一高 16px，选中保持原尺寸，左右内边距 5px，元素间距 2px。数字保持 10px 粗体，单位和容量为 8px 次要文字，单位前留 1.5px。分隔线缩短为居中的 6px，弱化对比；选中不额外增加胶囊强调。满仓保留红底白字，改为柔和细白边与轻阴影。

收入、生产与库存显示。城镇胶囊每行只显示一种资源，多个资源自上而下排列：所有资源行共用一个胶囊背景、边框和阴影，以建筑中心对齐，行高 16px、行距 2px，圆角保持 8px。胶囊宽度按最长一行计算，各行内容居中；未收益使用蓝灰单价行，已收益使用暖白收入行。红色库存警示接在所有单价／收入行下方，满仓资源在同一个红色库存胶囊内分行展示，未满仓资源不显示。选中不改变行数和内容。尚未产生过收购收益的城镇，单价胶囊使用深蓝灰底（--action-primary）、浅蓝灰细边（--action-subtle）和暖白数字（--surface-panel），与已产生收益城镇的暖白收入胶囊形成明显明暗差异；箭头、单位与分隔线使用半透明白色。首次收购后恢复暖白收入样式，暂时断货不切回蓝灰。此配色仅用于单价胶囊，满仓库存仍为红色。未开发城镇（尚无累计收购记录）常驻显示每种收购资源和单位价格「[货] → [钱]20/件」，不带收入加号，也不因尚未收购标红；选中时仍保留单价。首次收购后切换为实际收入，之后暂时零收入不切回单价。已开发城镇收入始终显示，包括零收入；选中时展开收购明细，取消选择恢复简洁收入。建筑生产胶囊仅选中时显示。产品或城镇仓库至少一种货满仓时才显示红底白字库存胶囊，未满仓与空库存即使选中也隐藏；完整库存可在详情面板的“物流与库存”中查看。

警示：整条胶囊变成醒目的红色。红底 #d63a2f、白字、白色细边加轻投影。红胶囊只陈述数值，不附加原因：产品或城镇仓库满了时库存胶囊变红。库存的其余状态不显示；未收益城镇的单价胶囊使用蓝灰底。钱和货同一写法：10px 图标 + 10px 粗体数字，产出和收入前加「+」，不写 $。

选中地图建筑。只保留选中轮廓、关联建筑高亮与常态胶囊；城镇胶囊逐种显示“货物 → 收入”；尚未交易的城镇显示“货物 → 单价/件”，首次交易后切换为分货物收入，不能合并成总收入，不展开本回合公式，不添加沿路数字。完整供需与收益统一在侧栏阅读。

经济反馈。建筑、工人和道路只有一次性购买费用；生产、运输、闲置均不扣金币，不收维护费或按件工资。收入只在城镇实际消费时产生。地图不显示持续费用或扣费飘字；选中建筑只显示投入、产出和库存。

查看瓶颈。默认地图用红色库存提示满仓；选中地块查看产出和原料，再通过详情中的物流流程图追踪上游供给或下游收购。

地图上不画等级；等级用罗马数字 I、II、III…，只在建造栏、详情标题、科技和升级按钮里显示，城镇等级对应时代。道路暂不显示运量或费用，货流是沿实际曲线移动的纯色小圆点。

地图与货物

地形色表示类别；货物靠图形辨认，颜色辅助。地图采用斜俯视六边形：地面纵向压缩到 65%（半径 51，实际宽约 88、高约 66），格心间距同步投影。建筑、地形小景、棋子与文字保持原比例；道路、迷雾边界、悬停、选中与建造预览共用同一地面坐标，点击与拖放按投影后的边界判断。

连续地貌决定路线

森林成片，山脉与湖泊跨板块延续，河流沿相邻水格蜿蜒。常规板块保留 2–3 格山水与可通行山口；草地不是默认直达走廊。森林道路更贵，山地必须绕行，水域在航道解锁后提供捷径。城镇与配套资源仍按产业顺序出现，每次探索保留陆路入口，不以孤立资源制造等待。

检查连续地貌示例：使用独立种子与逐块探索，比较紧凑、随机和直线拓展；示例不读写玩家进度。

货物用图形辨认，颜色辅助。

六种货物不是六种货币。小货点沿道路移动，面板始终配图标、名称与当地库存。

闲置地块使用实体微缩景观：草地与石块 62px、矿石 64px、森林 68px、山体 72px、水面 66px。保留素材原比例与左上光照，脚底落在地面前方（y=16，水面 y=22），高模型自然越过后缘；不添加投影或接触阴影，保留素材自身明暗与两侧交互轮廓；不显示棋子、产出或库存。悬停用浅色细轮廓，选中用主操作色实线，可建造用主操作色虚线，图案不变形。建筑略向上居中并放大，棋子自然散落在周围，产出和库存均放下方；多货物及选中详情可适度越界。下方「闲置板块」直接复用地图渲染器，不读写玩家进度。
