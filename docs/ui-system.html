布局与组件

界面说明只保留当前决策所需的信息：状态、价格、差额、产量、连接条件和操作结果。按钮或表格已表达的内容不在相邻说明中重复；稳定的玩法规则放在规则说明书，收入统计口径保留在数值悬停说明中。空详情只显示对象名称及必要状态。

连接与探索

新局配备免费伐木营、1 名工人和通往城镇的道路，余额 $2,600。玩家重点探索地图、解锁科技、选择位置和连接产业。加工建筑连接每种所需原料的运行中上游并雇工后，按工人和科技给出的固定产量持续生产；上游可共享，不逐件消耗或分配原料。未接通销售的产品保留，不设仓容，不停工。城镇不限量收购，道路长度不影响产量或结算；每件产品仅出售一次，优先售价最高的相连城镇。居民和时代每级增加基础售价的 25%，加成相加、最终单价四舍五入。

布局与尺寸

顶栏高 48px，保留余额、一项简洁收入速率、暂停、速度和更多菜单。收入以 12px 次要文字显示“+$100/回合”，采用近 30 回合实际收入均值，悬停说明统计口径；不显示预测值和重复标签。窄屏收入移到余额下方，顶栏仍保持 48px。两侧面板距顶部 62px、距边缘 14px，宽 340px，面板间距 10px。产业规划入口固定在左下。1050px 以下侧栏收窄，740px 以下转为底部堆叠。

文字与容器

原型使用 system-ui / Microsoft YaHei，正文 14px、行高 1.5。金额使用美元前缀，如 $1,200；收入与奖励使用 +$100，每回合收入写作 +$100/回合。余额 20px 粗体，普通面板标题 12px，圆角 12px。操作按钮统一遵守下方「统一操作按钮」规范，窄屏按单列排列，说明允许换行，费用始终靠右且不换行。导航和缩放等紧凑按钮至少 36px 高。

组件与交互

实时刷新保留现有按钮节点，只更新变化的文字与状态；鼠标悬停、按下及键盘焦点不因回合刷新重置。面板标题点击折叠；详情仅在选中对象时出现，对象名称作为标题。工坊首屏显示固定产量、工人数和连接状态。只提示「生产中」「待雇工」「待连接某原料的运行中上游」，不展示利用率、吞吐配平、堵仓或瓶颈警报。城镇显示不限量收购、单价和近期实际收入。建路只通过建筑详情的“从这里修路”进入，再点选另一座有建筑的板块；建筑板块上的透明道路点选区不能抢走修路目标，系统自动规划路线与总造价，玩家不选择路形；自动绕开其他道路和中途建筑，不交叉或共用路段，只允许在端点建筑汇合。无独立路线时明确提示。旧道路在建筑或分岔处划分管理范围，Esc 或取消退出。普通地图拖动只用于移动视图，点选道路只打开管理。道路不显示运量数字；点击或键盘选择道路时，两座建筑之间的独立道路统一高亮，焦点只改变路面颜色，不显示点击区边框；管理面板显示两端建筑名称、仅删除本连接的说明与本条道路的总退款额与“拆除整条路”。拆除中整条路显示虚线，停止新货进入，下一回合全额退款，完成前可“撤销拆除”。科技仅展示引擎中存在的项目，已移除的科技不留空卡片；可在地图地块或建筑详情直接解锁与升级对应科技；产业规划中的详情卡保留相同购买操作，区分解锁、升级与前置未满足。新增六项一次性研究沿用现有卡片、图标和森林绿解锁按钮，不新增视觉体系：石工筑路、水运工程、山地工程、水力机械、专业分工、深井开采。每卡显示分支、效果、前置和当前适用范围；研究完成标记「已研究」，条件未满足仍说明原因。依赖层级按先后排列，建筑解锁后原卡保留工艺升级。工坊详情列出当前生效的条件加成；工艺罗马数字仅表示基础工艺，不把条件加成混入等级。山地工程后的山格显示可修路、不可建造，山路复用现有道路画法。

信息精简：无选中对象时不显示空详情；窄屏直接进入地图，不弹设备提醒。游玩菜单只保留存档、重新开始与规则；玩法设计和 UI 规范从文档导航访问。保留目标与生产链用于规划；不展示增长曲线。详情采用 18px 对象标题、22px 关键数字、12px 次要标签；主操作使用蓝灰底，次级操作保持普通按钮。窄屏面板最多占可用高度的 62%，保留地图操作空间。

轻松探索提示

目标面板顶部只显示一条当前建议：有足够金币时引导探索迷雾，暂时买不起时写明差额与可立即做的手工生产，新市场缺少生产者时引导查看产业规划。建议只引导玩家操作，不自动购买、不读取或改写存档；保留探索、建造和研究的自主选择。费用采用引擎当前价格，建议随余额和进度更新。目标奖励可资助下一步探索，避免把攒钱当作主要玩法。

示例：下一步 · 探索一块新地图 · $400；金币不足时显示「还差 $120 · 点击伐木营手工生产，也可继续自动经营」。

详情中的科技操作

选中未开发地块时，按其地形展示可用建筑；未解锁但已满足前置的建筑直接显示「解锁」与费用，购买后原处变为「建造」。选中工坊时显示对应工艺的升级按钮；选中城镇时显示时代升级。可研究的运输科技出现在道路详情；水域与山地科技出现在对应地形详情；条件生产研究出现在适用工坊详情。前置未满足时只简短指出缺少哪项科技，不呈现无法购买的深层分支。按钮沿用主操作与升级色、买不起状态和费用布局，购买后即时刷新详情。

建筑详情

标题配建筑图标。详情按「状态与配方 → 固定产量／工人数 → 上游连接 → 操作」排列；数据使用无阴影浅色区，产量 24px、单位 11px，工人数独立对齐。原料连接用紧凑行，资源图标、名称和带图标的状态各自对齐。说明只保留必要效果，不重复解释规则。操作按钮至少 64px 高，1px 清晰边框、2px 底部阴影和 9px 圆角；悬停提亮、按下下移 1px、键盘显示焦点环。雇工沿用蓝灰、工艺沿用陶土，手工和修路使用暖白实体按钮。按钮左侧 24px 操作图标、中央标题与简短增量、右侧 18px 费用配金币图标；图标始终配文字。满员保留数据状态，买不起按钮压暗且禁用。辞退和拆除折叠在管理中。窄屏保持单列操作，不压缩费用与图标。组件示例复用相同样式，只演示反馈，不读取存档。

统一操作按钮

地图详情、产业规划、管理区和组件样本共用一个操作按钮组件。左侧 24px 操作图标，中间 14px 粗体「动作＋对象」与 12px 简短效果，右侧 18px 金额及 18px 金币图标；退款在右侧标为「退回」。按钮宽度随容器变化，最小高度 64px，内边距 12px，圆角 9px，边框 1px。没有效果或金额时省略对应项，不填充无用说明。配方、效果和金额不因所在界面改变格式。

解锁与研究使用森林绿和锁图标；建造使用蓝灰和加号；升级使用陶土色和齿轮；删除、拆除与辞退使用暖白底、红色文字及描边和叉号。辅助操作使用暖白。颜色由动作决定；产业规划入口是导航按钮，不随可研究数量变成升级按钮。流程图节点仍为选择卡片，选中使用蓝灰焦点轮廓。

可用、悬停、按下、键盘焦点、不可用和已选中复用同一套状态：悬停变深，按下下移 1px，键盘焦点为 2px 外环；金币不足或前置未满足时保留动作颜色、统一降低至 55% 不透明度，禁止提交并显示原因。已选中保留动作颜色与外环；完成的研究显示静态完成状态，不伪装成可点击按钮。按钮正文不重复费用或状态。地图迷雾使用紧凑两行尺寸，仍沿用解锁绿、暖白文字和同一禁用、悬停及焦点规则。

对称的科技与建筑详情

科技与已建工坊共用详情渲染器，顺序固定为：图标名称与罗马等级 → 原料／工坊／产品流程 → 固定产量与工人数 → 工艺升级效果 → 同名同价升级按钮 → 场景操作。科技标注「全部同类工坊」，建筑标注「当前建筑」，不混淆全局工艺与本地总产量。建筑的原料图示附连接状态；科技的原料图示可跳转上游。科技提供建造，建筑提供雇工、手工和管理；工艺升级的名称、等级、图标、费用和效果完全一致。城镇保留交易表，并复用时代效果图解与升级操作。

科技详情图解

详情优先图解：原料图标 → 工坊 → 产品，多个原料纵向并列；原料可点选已发现的上游。工艺升级用工人图标、当前产量 → 升级产量、产品图标表现，注明「每人／回合」，不重复等级摘要。时代展示城镇售价加成的前后数值。运输与生产研究使用条件图标 → 效果数值，保留邻湖、满员、每工人等必要条件及自动生产适用范围。建造地形、单价和已建数量用紧凑图标数据；研究前置用图标按钮与箭头。文字只作名称、单位和无法图解的限制。复用共享图解渲染器，示例使用独立世界，不读取存档。

产业规划弹窗

阅读顺序统一为名称 → 等级／状态 → 核心效果 → 操作与费用。所有等级使用加粗罗马数字（如 II → III）；前置层是布局层级，不使用等级造型。介绍中的资源使用「资源图标 + 加粗资源名」，金币使用「金币图标 + 加粗金额」，复用同一格式化器；建筑名称不拆成资源词，正文与按钮不重复嵌套图标。节点只放短效果或配方，完整说明放入右侧，正文保持常规字重，关键产量和增量加粗。基础采掘、木板与航道按前置逐步开放；工具、铁、纸张、书籍和机械产业需先探索到对应市场，炭窑随机械市场开放。时代的四次升级分别需探索 2、4、8、12 块。已拥有科技始终可见；科技树中未发现节点显示灰色禁用按钮和连线，按钮仅含锁图标与「未发现科技」，不展示科技名称、建筑图标、价格、效果或依赖文字，不能选择或购买；生产链也保留所有产业的连线与灰色禁用节点，标注「未发现产业」，隐藏具体名称、配方和价格；满足发现条件后原位恢复可点击节点。购买检查与显示共用同一条件，旧档已解锁科技保留。

科技状态在两种流程图中一致：蓝灰「可解锁」、陶土橙「可升级」、中性「金币不足」、绿色勾选「已满级」、锁图标「前置未满足」，状态始终附文字。建筑节点显示「工艺 II」，未解锁显示「工艺未开启」；时代显示「II / V」与时代名称；一次性研究显示「未研究」或「已完成」。工艺无等级上限，不额外显示「可持续升级」说明，不虚构满级。节点底部显示本次解锁／升级费用；满级改为完成标记。详情保留效果、操作费用与不足差额，移除重复等级状态摘要；图中不显示层级标题。入口、节点和详情按同一购买条件实时更新。沿用逐层展开，未满足的远期节点不提前展示。

产业规划入口始终使用蓝灰导航样式，可购买项目数量只更新文字，入口始终可以打开。地图保留一个「产业规划」入口，合并原建造栏、科技树与生产链侧栏。原生模态弹窗提供「生产链」「科技树」两种流程视图，共用选中节点和右侧详情；生产链实线箭头表示上游连接关系，科技树虚线箭头表示研究前置，工艺前置明确标注 II。初始只显示已拥有节点及前置与探索条件均满足的下一层节点；购买前置后逐层展开，尚未发现节点在科技树中保留轮廓与连线。节点保留现有建筑／资源图标与蓝灰选择轮廓，显示名称、配方／效果和状态；详情提供解锁、工艺升级、费用及「到地图建造」。选择建造后关闭弹窗，在地图点选合适地形；入口旁提示当前待建建筑并提供取消。弹窗打开期间暂缓回合，关闭恢复原暂停状态；Esc、关闭按钮均可关闭，键盘焦点回到入口。图可缩放、适应全图、滚动查看；移除跳转、定位选中、连线说明与层级标题。弹窗顶部避开 48px 游戏顶栏，遮罩从顶栏下方开始，原余额始终清晰可见，不在弹窗重复显示；窄屏图在上、详情在下且分别滚动，保留文字可读尺寸。样本只使用独立新世界，不读写存档。

扩展产业

铁产业之后依次引入纸张、书籍和机械市场；木炭仅作加工原料。新增炭窑、造纸坊、印刷坊、机械厂均落在草地，沿用 54px 模型框、暖白面板、蓝灰购买与陶土升级。图标使用等距视角、左上光与暖灰／蓝灰／陶土色块：炭窑用圆窑与炭堆，造纸坊用晾纸架，印刷坊用压印机与书本，机械厂用齿轮与烟囱。纸张为暖白叠页、书籍为蓝色书封、木炭为深灰块、机械为金属齿轮。产业规划以工坊节点与有向连线展示加工品流向；选中节点突出关联线路及原料标签，完整配方保留在详情。窄屏可滚动、缩放与定位，节点文字不挤压。组件样本展示三种上游连接与待连接状态，不读取存档。

组件状态

颜色与层级

画布 → 面板 → 内嵌区域，依靠明度、留白和边界分层。主要数字用字重和字号突出，不把所有收入、价格都涂成金色。

状态

操作与选择

按钮结构、动作颜色和所有交互状态统一遵守「统一操作按钮」规范。金币不足与前置未满足时禁用提交并显示原因；对象、流程节点仍可选中查看条件。选中建筑时突出关联生产链，链外地块与道路降至 30% 不透明度。地图迷雾先选中，再显示独立的森林绿「解锁」按钮及费用；再次点击按钮才购买。金币不足时按钮禁用，余额足够后恢复；选中别处隐藏按钮。详情只保留迷雾名称与费用，避免重复购买入口。

连接状态

工坊详情用一个产量数字和原料连接清单：已接通显示上游名称，未接通说明需要运行中的上游。增加工人、升级工艺显示固定增量。城镇详情列单价与实际收入，明确不限量收购；居民升级说明售价加成。管理区保留修路、辞退与拆除。关联线路只帮助理解产业，不承载供需诊断。

地图反馈

建筑保持现有 54px 图标、院地、工人和道路风格。地图显示城镇单价／实际收入与选中建筑产量，复用暖白胶囊和蓝灰未开发城镇胶囊。不显示原料库存、红色满仓、缺料警报或效率。详情说明所需连接，接通后产出固定增长。生产、运输与闲置无持续费用。道路运输模型仅表现活跃连接，不代表调度压力或到货倒计时。

地图上不画等级；等级用罗马数字 I、II、III…，只在建造栏、详情标题、科技和升级按钮里显示，城镇等级对应时代。道路暂不显示运量或费用，运输是纯装饰：按活跃产业连接覆盖完整路线：短路与短航道也必须有运输动画。优先合并同向连续货流的最长线路，跨过中间建筑与岔路，不按地块、路段或建筑对重复生成；覆盖过的路段不再分配第二只，剩余分支再补充驴或船。每条线路单向行进，水陆交界切换运输模型；断货的已有行程可走完，不启动新行程。全地图最多同时 6 个运输模型，多余分支公平轮换，所有有货流的路段最终都得到展示。动画保留近期货流方向，避免每回合频繁闪现；道路拆除或流向反转后重新规划。不表示货量、货种或到货时间。小驴采用灰褐身体、长耳、浅色口鼻与陶土色驮包，约 26px 宽，交替迈腿并轻微起伏；船约 28px 宽，轻轻摇摆。保持直立，只按行进方向左右翻转，不随曲线倒转。接近端点淡入淡出，错开各段节奏；暂停时静止，减少动态效果偏好下保留静态模型。装饰不拦截点击，不盖住建筑胶囊。

地图与货物

地形色表示类别；货物靠图形辨认，颜色辅助。地图采用斜俯视六边形：地面纵向压缩到 65%（半径 51，实际宽约 88、高约 66），格心间距同步投影。建筑、地形小景、棋子与文字保持原比例；道路、迷雾边界、悬停、选中与建造预览共用同一地面坐标，点击与拖放按投影后的边界判断。道路的透明点击区不显示边框或虚线；悬停、选中和键盘聚焦只改变道路本体颜色。

连续地貌决定路线

森林、湖泊、山脉与草地形成更大、更连续的片区，跨板块优先连接同类地形，减少单格交替。新增城镇与岩石、铁矿资源点优先隔开两个地块（六边形距离至少 3）；在受限的探索位置，以地图连通和产业供应为先。城镇板块不混入森林资源，森林是成片资源地形，不按单点计数。开局预置的伐木营与城镇保留教学道路。每块探索仍保留陆路入口。森林道路更贵，山地工程研究前必须绕山，研究后可按 ×4 系数铺设山路；水域在航道解锁后提供捷径。城镇与配套资源仍按产业顺序出现，每次探索保留陆路入口，不以孤立资源制造等待。

检查连续地貌示例：使用独立种子与逐块探索，比较紧凑、随机和直线拓展；示例不读写玩家进度。
