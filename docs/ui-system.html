布局与组件

布局与尺寸

顶栏高 48px；两侧面板距顶部 62px、距边缘 14px，宽 340px，面板间距 10px。建造栏固定在左下。1050px 以下侧栏收窄，740px 以下转为底部堆叠。

文字与容器

原型使用 system-ui / Microsoft YaHei，正文 14px、行高 1.5；所有金额统一使用美元符号前缀，如 $100、$1,200；收入与奖励写作 +$100，每回合收入写作 +$100/回合，金额进度写作 $100 / $200，不再附加货币单位。余额 20px 粗体，面板标题 12px。面板圆角 12px、6px 背景模糊；按钮圆角 7px、内边距 8px × 12px。付费按钮采用左右布局：左侧 14px / 700 粗体标题，下方 12px 常规字重说明，降低亮度；右侧 18px / 750 等宽数字费用，不换行。费用不再混在说明中。建造栏采用图标加两行文字：上行建筑名称与等级为 14px / 700，下行费用为 12px / 400、85% 不透明度，与名称左对齐并间隔 3px；可建、选中与买不起状态均保持此层级。窄屏详情操作纵向排列，说明可换行，费用保持靠右。标题与费用保持高对比，升级费用沿用白色。

组件与交互

面板标题点击折叠；详情先展示对象、状态、工人或居民与主要动作，再展示产线诊断和近 30 回合数据。拆除、辞退与修路入口收进「管理建筑」。科技使用分层卡片，区分解锁、升级与前置未满足。

组件状态

颜色与层级

画布 → 面板 → 内嵌区域，依靠明度、留白和边界分层。主要数字用字重和字号突出，不把所有收入、价格都涂成金色。

状态

操作与选择

建造与解锁保留蓝灰主按钮；升级（含工艺、金手指与时代提升）使用陶土橙底、白色文字的 .upgrade 按钮，以 --action-upgrade 系列色值统一默认、悬停与按下状态。价格文字同样保持白色；键盘焦点保留蓝色轮廓，禁用与买不起沿用现有压暗状态。选中建筑时突出关联生产链，链外地块与道路降至 30% 不透明度。取不到手的东西只有一套画法：.costly（买不起）与 .locked（前置未满足）共用同样的压暗，不靠配色互相区分——.locked 另带一枚锁图标说明被锁住，这就够了。买不起仍可点击，让玩家先规划再攒钱。这套压暗在建造栏、科技卡与详情面板购买按钮上一视同仁。地图迷雾板块整块就是一个按钮，不在板块里再套一个按钮——没有底板、没有边框，板块自己的底色就是按钮的底色，「解锁」与价格直接落在上面。买得起时板块底用实的 --terrain-fog 配主要文字，悬停提亮、可聚焦、指针为手型；买不起时底色换成 --terrain-fog-costly（一块几乎融进地图衬底的淡色），文字压到 55%，并且整块不可交互：不可点、不可聚焦、无悬停反馈。文字留在原处是为了让玩家看见「这里有个东西，只是现在按不动」，而不是以为这块地什么都没有。这一点与建造栏相反——建造栏买不起仍可点，是为了先规划后攒钱；板块没有可规划的余地，点开也只有一个按不动的按钮，索性不让点。建造栏里每个建筑本身就是一个按钮：可建（买得起）直接用主按钮的深蓝底，与科技卡上的「解锁」同级；选中待放置时压到 --action-pressed 并加一圈 --action-subtle 外环；买不起退回普通按钮并压暗。选中态优先于压暗——买不起的建筑一旦被选中，就是当前动作，全强度显示，金币不足由放置时的提示承担。

物流流程图

选中一格后，详情面板从上到下画一条物流链：建筑是「来源 → 原料仓库 → 建筑 → 产品仓库 → 去处」，城镇每种货一条「来源 → 仓库 → 每回合吃掉 → 收入」。每一节一张小卡：左边写这一节是什么和次要数字（送来、产能、维护费、收购价），右边是这一节的主数字（库存 n / 上限、本回合投入 → 产出、每回合收入）；节与节之间一条竖线，线上写流量。数字取近 30 回合的每回合平均。出问题的那一节标红（堵住、白花钱）或琥珀（空了、等货），右上角贴和地图上同一句话的红色小标签；图下的结论写原因和对策。

地图反馈

目标：默认地图保持简洁，用库存提示积压，选中地块查看产出与瓶颈。建筑和城镇一样，建筑使用 54px 图标框，中心在 (0,-12)，顶部可略越过地块后缘，脚部落在地面上；脚下保留道路同色（--road-dirt）的实色扁椭圆土色底影，与路面自然衔接，模型保持原透视；棋子使用 16px 图标框与脚下接触阴影，以稳定的散点分布在建筑两侧与前侧，按地块固定轻微偏移，刷新不重新随机。两个独立胶囊采用暖白底、细灰边、轻阴影：常态高 14px，默认不显示生产速率或城镇收入胶囊；库存有货时放在下方 y=12；横向间距 1.5px、内边距 4px，图标与数字间隔 1px；长内容及选中详情允许外扩，不压缩文字。选中详情移到模型下方，高 18px、间隔 2px。胶囊里的元素之间用细竖线隔开。

生产胶囊 · 选中时显示。默认隐藏生产速率与城镇收入，包括产出为零时；选中地块后显示本回合投入、产出或收入，取消选择即隐藏。

库存胶囊 · 产品仓库有货才显示。开头一个仓库图标，竖线后是产品的库存「[货] n/上限」（「/上限」8px 灰色），例如「[仓库] | [木板] 20/20」；城镇列它收的货。原料库存不在地图上显示，点开再看。产品仓库空了就整条不出现。

警示：整条胶囊变成醒目的红色。红底 #d63a2f、白字、白色细边加轻投影。红胶囊只陈述数值，不附加原因：产品或城镇仓库满了时库存胶囊变红。其余不上色。钱和货同一写法：10px 图标 + 10px 粗体数字，产出和收入前加「+」，不写 $。

点一格 · 展开成详细信息。选中的格子两条胶囊写全：生产胶囊「本回合 | [钱]维护费 [原料]n → +[产品]n」（城镇「本回合 | [货]n → +[钱]n | …」），仓库胶囊列出每一种货，包括空的，都写 n/上限；问题数字用红字。展开的胶囊可以盖住邻格，取消选择收回。更完整的上下游关系在详情面板的物流流程图里。

每回合动画。只有维护费：每回合从板块上方飘出一个红色的「−[钱]n」（11px 特粗，白色描边，钱图标 11px，1.1 秒上浮 14px 淡出），不常驻。不飘「+1」产出，产出在选中地块后查看。维护费每回合固定：原料建筑 2 + 每名工人 2，加工建筑 4 + 每名工人 6；城镇没有。

查看瓶颈。默认地图用红色库存提示满仓；选中地块查看产出和原料，再通过详情中的物流流程图追踪上游供给或下游收购。

地图上不画等级；等级用罗马数字 I、II、III…，只在建造栏、详情标题、科技和升级按钮里显示，城镇等级对应时代。道路暂不显示运量或费用，货流是沿实际曲线移动的纯色小圆点。

地图与货物

地形色表示类别；货物靠图形辨认，颜色辅助。地图采用斜俯视六边形：地面纵向压缩到 65%（半径 51，实际宽约 88、高约 66），格心间距同步投影。建筑、地形小景、棋子与文字保持原比例；道路、迷雾边界、悬停、选中与建造预览共用同一地面坐标，点击与拖放按投影后的边界判断。

货物用图形辨认，颜色辅助。

六种货物不是六种货币。小货点沿道路移动，面板始终配图标、名称与当地库存。

闲置地块使用居中的地形小景，最长框边 42–48px，保持素材原比例并给斜边留白；不显示棋子、产出或库存。悬停用浅色细轮廓，选中用主操作色实线，可建造用主操作色虚线，图案不变形。建筑略向上居中并放大，棋子自然散落在周围，产出和库存均放下方；多货物及选中详情可适度越界。下方「闲置板块」直接复用地图渲染器，不读写玩家进度。
