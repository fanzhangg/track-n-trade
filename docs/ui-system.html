第一眼：结论与下一步。异常诊断配浅色底；主要操作用钴蓝。

# 排名

最值得先解决的三条路

红、橙、黄只表示相对排名，并不表示危险等级。未进前三的道路保持深棕。

状态叠加规则选中瓶颈道路时，保留红橙黄路芯，用纸白间隔 + 钴蓝外环表达选中。缺料和满仓使用「△ + 原因」；锁定使用「锁定 + 前置条件」，不依赖透明度。
03 / WORLD PALETTE

地图有质感，信息有秩序。

以 Dorfromantik 的田园感为方向，提升草地、森林、湖泊与城镇的饱和度；借鉴实体桌游的清晰分区，让每类地形都有独立色相。地形色仅表示类别，不表示可点击、收益或警告。

货物用图形辨认，颜色辅助。

六种货物不是六种货币。小货点沿道路移动，面板始终配图标、名称与当地库存。

地图落地规则地形保留纹理或图形；小字放纸白标签底。普通道路用深棕，货点加纸白描边。迷雾保持统一外观，是否买得起用边缘与价格说明表达，不改变地形语义。
