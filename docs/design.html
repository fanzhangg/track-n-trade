玩法设计

Tracks & Trade 是一个单人 idle 物流建设游戏。玩家点击、雇人、铺路、揭开地图、买科技；系统自动把货送到该去的地方、卖成金币。核心乐趣只有一句话：发现东西没有到达需要它的地方，设计一张更好的网络，看它自己运转；再用它挣来的钱去揭开下一块地。

休闲探索

复杂度集中于探索地形、解锁科技和选择产业位置。生产线接通并雇工就固定产出，不要求玩家诊断瓶颈、竞争原料或配平供需。保留金币投资、自动收益与全额退款。

三条循环

连接产业获得固定收入；探索发现新地形与市场；科技解锁新建筑、路线与产量成长。开局自带免费伐木营、1 名工人及两段道路，余额 $2,600 可自由投资，无首路预留。

时钟与统计

1 回合 = 2 秒（1×），2× / 5× 只压缩时间；所有货物整数件。页面隐藏暂停，不补离线收益。顶栏只显示近 30 回合实际收入均值；经济模型展示长期趋势，不保证逐回合常数。

探索生成规则

地图由七格花铺成。起始花固定：原木城镇、森林、草地和山；其余板块在购买时由种子、当前缺口和解锁顺序决定，方向自由选择，自动定向，不提供旋转或预览。

探索按「新买家 → 配套资源」交替推进：石头城镇 → 岩地 → 木板城镇 → 森林与加工空地 → 工具城镇 → 岩地 → 铁城镇 → 贴山铁矿。若旧地图存在缺失原料，先补原料；多种缺口逐块补齐。工厂建在资源上也算已有产地，不会因雇工或建厂把探索卡在补森林。

发现顺序引导科技，但不会免费解锁科技。先展示新的销售机会，玩家再决定投资哪条链。所有八种可售商品出现后，城镇引入双货需求，资源板块补其配套原料；挑战转向共享原料、选址与扩容。有限的配方不意味着无限的新机制。

森林、山脉和水域跨板块连片生长；常规板块有 2–3 格山水，河流以狭长水格延续。草地山口与绕行路线保持连通，未探索邻块保留陆路入口；航道解锁后可以跨水取捷径。铁矿邻山，城镇不与所需原料同块或紧贴；石头城镇周围也可有森林。产业发现节奏不变，地形与朝向随种子和邻地变化。

前期机制密度

起始板块教会原木销售；前两块引入采石；第三、四块引入单输入加工；第五、六块引入多上游连接；第七、八块引入矿山与炼铁。保证机会出现，不强迫玩家立即建设；额外需求允许先规划再攒钱。

接通就生产

每座工坊最多 3 名工人。连接每种所需原料的运行中上游、并雇用工人后，每回合固定产量 = 工人数 ×（1 + 对应工艺等级）+ 条件科技加成。上游自身也必须满足连接条件且有工人；同一个上游可支持任意多个下游，无需配平各段产量，不逐件消耗原料。连接关系可经过任意长度的道路网络。

未接通市场的产品会保留，不设库存上限，不会停工。道路断开或上游最后一名工人被辞退时，对应下游停止生产；恢复条件即可继续。手工生产可选，每次为 1 + 工艺等级，不需要本厂工人，但加工厂仍需运行中的上游。

城镇与收入

城镇对自己收购的商品不限量收购。每回合自动卖出所有相连地块的可售库存，每件货只出售一次，优先选择有效单价最高的相连城镇；同价按固定顺序选择。道路长度没有延迟或吞吐惩罚。选择城镇只查看，不手工卖货。

有效单价 = round（生成时基础单价 × [1 + 25% ×（居民数 − 1 + 时代升级数）]）。每城镇最多 3 名居民，每次加居民提升本城镇基础售价 25%；时代升级提升全图基础售价 25%，加成相加。历史收入按成交时单价记录，不随升级改写。

居民费用 = round（各商品基础单价之和 × 12 × 1.5^(已有居民数−1)）。时代费用 = 2,400 × 2^当前时代升级数，最多升级四次。

科技与扩容

解锁顺序：采石场 → 锯木厂 → 石匠铺 → 矿山 → 铁厂；锯木厂同时开启可选航道。每种建筑解锁后，同一张科技卡改为购买该类工艺。时代提升全图城镇售价，工艺提升全图同类工人的产量，价格只依赖类型与等级。

新产业接在铁之后：纸张市场 → 森林 → 书籍市场 → 岩地 → 机械市场 → 铁矿。所需森林等原料若缺失仍优先补齐；新建筑使用草地，不增加地形或重绘已探索板块。已有存档继续探索即可发现新市场。八种可售商品均引入后，再生成双货市场。

纸张可以直接卖，也可和石头工具一起制成书籍；木炭不能直接卖，机械需要木板、铁、木炭同时供应。原木上游可供造纸、烧炭、炼铁、木板与工具共享；各链独立按工人和科技生产。

每座新增工坊仍最多 3 名工人，独立工艺全图生效；水力机械、专业分工同样适用。研究、建造、工人与工艺各自付费；生产与运输不收费。

保留旧铁配方，避免旧档断供。木炭作为新增装配支路的燃料，而不是替换旧生产线输入。新增商品按原产业之后的次序进入地图，开局节奏不变。科技可提前研究，但需发现市场才有销售收益。

分支科技

参考 Roads & Boats 规则书第 16 页的运输工厂、矿山改良与新矿井研究：借鉴分支投资与能力解锁，不照搬鹅、纸、研究点、矿藏耗尽或载具运力。当前游戏仍以金币购买研究，已有工坊即时生效。

水力利用生成器已有的连续湖泊，分工鼓励满员集中生产，深井适合多矿山供货。山地工程是矿业之后的昂贵捷径，不作为任何板块的必需通行条件。地图仍先给买家、再补对应原料，山湖布局及陆路连通约束不变。

基础工艺保持可重复成长；条件研究是一次性、固定收益。石工筑路需累计新修 $12,000 基础道路才省回 $2,400，水运工程在没有石工筑路时需 13 段湖路、叠加石工筑路时需 16 段湖路；选择应基于扩张计划。工人和科技固定增加产量，连接相应城镇即可转化为收入，不受上下游产量限制。

下方固定经营策略仍作为原基础路线对照；不声称它会自动选择可选研究。新增回归覆盖条件加成、实际销量、路价退款、旧档迁移与相同种子地图一致性。

真实引擎经济模拟

直接运行 engine.js：优先接通新产业，再探索；较长等待时选择可回本的工人、工艺或售价升级，不按供需缺口投资。模拟不手工点击也可拓展全部八种可售商品。以下是固定策略的可复现结果，不代表所有玩法或种子的体验。

所有建造费用只支付一次。工艺费依类型与等级增长；城镇不限量购买，居民和时代提升售价。未售产品无限保留；连接上游无需消耗其产量。

新产业与购买记录

界面与目标

界面规范及可检查样本以 设计系统 为准。工坊可以手工生产；城镇只有自动收购。产业规划流程图用于查看上游连接与科技前置，价格与新增能力在购买前显示。

目标仅保留每回合收入和已探索板块。收入目标翻倍，探索目标每次加一。达标自动结算，奖励为近期每回合收入的两倍，最低 800、最高 1,200；不是产线收入，可帮助支付新地图上的道路。不因统计回落撤销成就。

实现与验证

engine.js 是规则唯一来源。输出生产、库存与实际销售保持整数账本；加工连接不再消耗上游实物。统计保留成交收入，装饰交通独立于货物账本。v25 迁移将旧在途货物落到所在／即将到达地块，清除旧派货预约与瓶颈警报，不改变现金、地图、科技及购买退款记录，重复加载不重复迁移。

本次取舍

去掉逐件原料竞争、满仓停工、有限收购和供需诊断。保留七格探索、现有地形生成、完整产业链及科技图。成长来自工人与科技带来的固定产量，以及居民和时代带来的售价提升。
