# Idle terrain bitmaps

Six transparent 512×512 PNG decorations for empty map tiles. Generated with the built-in ImageGen workflow, then trimmed and losslessly packed for the game.

| File | Visual relationship |
| --- | --- |
| `forest.png` | Reuses the evergreen tree silhouette and foliage/trunk materials associated with the logging camp. |
| `rock.png` | Reuses the warm limestone material associated with the quarry. |
| `ore.png` | Reuses the dark blue-slate ore and terracotta inclusions associated with the mine. |
| `grass.png` | Sparse grass and flowers leave the tile visually open for processing buildings. |
| `mountain.png` | Tall, sheer twin peaks communicate permanently unbuildable terrain. |
| `lake.png` | Low open-water ripples, lily pad and reeds communicate waterway-only passage. |

All images use a transparent background, three-quarter low-poly construction, flat three-tone shading and top-left lighting. No source image was copied into the result; existing project icons were supplied as style and material references.
